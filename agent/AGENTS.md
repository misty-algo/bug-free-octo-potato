## ⛔ 六条不可协商红线（任何情况都适用）

1. **金额全链路用「分」整数**，MUST NOT 用 float/double 表示钱。
2. **只动自己域的代码与集合**；要读别人的数据走对方的 service / gRPC，MUST NOT 直连别人的表。
3. **schema 以数据字典为唯一依据**；要改字段/集合必须先人工确认并更新字典，代码先行一律打回。
4. **状态机与资金守恒是事故级红线**：订单状态变更走乐观锁 + 状态日志留痕；每一单满足 `乘客实付 = 平台佣金 + 司机收入 + 平台补贴`。
5. **AI 不碰仓库钥匙**：MUST NOT 自行 `git push` / 强推 / 改写历史 / 绕过 CI；是否 commit 永远由人决定。
6. **AI 不改约束本身**：MUST NOT 修改本文件与 `Agent约束规则/` 下的任何文件。发现问题 → 报告负责人，人工裁决。

口径冲突、文档缺失、需求含糊、不知道该不该做 → **停下来提问**，不要自行脑补一个实现糊过去。
